プライバシーポリシー

n8n-app（以下「本アプリ」）は、運営者本人が自分の YouTube チャンネルを管理するための個人用ツールです。

取得する情報

運営者本人の Google アカウントの承認を得て、次の情報にアクセスします。

  • 運営者自身のチャンネルの動画情報（タイトル、公開状態など）
  • 運営者自身の動画の統計（再生数、視聴維持率、登録者数の増減など）

利用目的

動画の投稿・公開予約と、自分の動画の成果の分析にのみ使います。それ以外の目的には使いません。

第三者への提供

取得した情報を、第三者に提供・販売・共有することはありません。広告にも使いません。

保管

認証情報と統計は、運営者本人の端末内にのみ保管します。

YouTube API サービスについて

本アプリは YouTube API サービスを利用します。YouTube 利用規約および Google プライバシーポリシーが適用されます。Google アカウントのアクセス権は、Google アカウントの権限設定ページからいつでも取り消せます。
